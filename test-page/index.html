Night Neutralizer — local test bench

Everything here is generated in the browser, so there are no binary test assets. Serve this folder over http (see npm run testpage); content scripts do not run on file:// URLs unless you explicitly allow it.

1. Video: dark scene, bright scene, hard cut, flash

The video element on the left is fed from the canvas on the right via captureStream(). The extension only processes <video>, so the canvas is your unprocessed reference: any difference you see is the tone mapping. Watch the shadow detail in the dark scene and the sky in the bright scene, then watch the flash at the end of each cycle.

2. Audio: whisper / normal / blast loop

A generated 12 s WAV loop that steps through −42 dBFS, −24 dBFS and 0 dBFS material. With the extension on, the quiet part should be clearly audible and the blast should stop being startling. Use the element's own volume and mute controls to confirm they still work.

3. Lifecycle: dynamic insertion, replacement, removal

Exercises the MutationObserver paths: new elements must be picked up without a reload, moved elements must not be re-processed, removed elements must be cleaned up.

4. Static test pattern (for pixel comparisons)

A fixed grey ramp, so you can compare the same frame with and without processing. Toggle the extension and watch the dark end of the ramp separate while the white end pulls back. The automated smoke test measures exactly this by screenshotting the element.

5. Nested frame

The manifest injects into all frames, so an embedded player is processed too. This iframe runs its own copy of the content script.
